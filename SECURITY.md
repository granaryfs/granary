# Security policy

## Report a vulnerability privately

Use **Report a vulnerability** in the repository's **Security and quality**
tab when the form is available. You can also email the maintainer at
[adrian@adrianana.com](mailto:adrian@adrianana.com).

Include the affected version or commit, the impact, and the steps needed to
verify the report. Remove credentials and unrelated private data from any
files you send. Keep the report and discussion private while we assess the
impact and coordinate disclosure.

## Supported versions

Granary is pre-release. Include the exact commit if you are running a build
from source.
